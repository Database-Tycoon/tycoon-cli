## Known limitations

Carried forward from 0.2.1 until the PR that closes each one lands:

- **The legacy-table warning does not reach multi-resource sources.**
  Migrating a flat filesystem source to the `resources:` shape leaves the
  old generic table behind silently. Tracked in
  [#244](https://github.com/Database-Tycoon/tycoon-cli/issues/244).
- **A glob that matches nothing still truncates.** Tracked in
  [#240](https://github.com/Database-Tycoon/tycoon-cli/issues/240).
- **The city is a plan, not yet a simulation.** Vehicles and guests are
  simulated but not drawn. Fix open as #250.
- **Coverage milestones are not surfaced yet.** The renderer does not read
  the `achievements` block. Fix open as #251.
- **The renderer's test suite is not CI-gated yet.** #256 and #253 land the
  gate.
- **Remote object storage is still unsupported.** `s3://`, `gs://` and
  `az://` are recognised only well enough to be skipped by the local-glob
  check.
