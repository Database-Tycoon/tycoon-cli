# Spike scripts

Exploratory scripts carried over from the pipeline-city repo before it was
deleted. They are not part of the package and nothing in `tycoon city` runs
them, but they are the only worked examples of how several `tycoon_city.sim`
town-planning modules are driven — `town_endings` in particular has no other
caller anywhere in this repo.

They were gitignored in their original repo, so they are absent from the
history bundle too. Kept here rather than lost.
